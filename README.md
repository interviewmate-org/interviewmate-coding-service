# Coding Service

This repository contains the backend coding service for InterviewMate_v2. It provides endpoints for running code, evaluating solutions, and supporting interview-style coding challenges.

## Features

- Execute code in multiple languages
- Validate candidate submissions
- Return output, errors, and execution results
- Designed for integration with InterviewMate frontend and platform services

## Installation

1. Clone the repository

## Usage

- Use the configured API endpoints to submit code for execution
- Send source code, language, and input data in the request payload
- Receive execution results, stdout, stderr, and status
